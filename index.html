Project Overview

A practical demonstration of a complete DevOps delivery workflow from source code to monitoring.

What is this project?

This project demonstrates a complete DevOps CI/CD pipeline for a Java Maven web application. The application is built using Maven, automated with Jenkins, packaged into a Docker container, pushed to DockerHub and deployed on Kubernetes.

  • ✓ Automated CI/CD pipeline
  • ✓ Docker containerization
  • ✓ Kubernetes application deployment
  • ✓ Ansible automation
  • ✓ Prometheus monitoring
  • ✓ Grafana dashboard visualization

Project Goal

The main objective is to automate the complete application delivery lifecycle and demonstrate how different DevOps tools work together.

  • 1 Developer commits application code.
  • 2 Jenkins automatically builds the application.
  • 3 Docker creates the application image.
  • 4 Kubernetes deploys the container.
  • 5 Prometheus collects metrics.
  • 6 Grafana visualizes monitoring data.

Pipeline Steps

How the application moves through the DevOps lifecycle.

01

Developer Pushes Code

Application source code is committed and pushed to the GitHub repository.

02

Jenkins Checkout

Jenkins retrieves the latest source code from the GitHub repository.

03

Maven Build

Maven compiles and packages the Java application.

04

Docker Image Build

The application is packaged into a Docker container image.

05

DockerHub Push

The Docker image is pushed to DockerHub for centralized image storage.

06

Kubernetes Deployment

Kubernetes Deployment and Service manifests are applied to deploy and expose the application.

07

Ansible Automation

Ansible playbooks are used for configuration and deployment automation.

08

Monitoring

Prometheus collects metrics and Grafana visualizes the monitoring information.
